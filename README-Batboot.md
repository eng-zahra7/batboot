# تشغيل مشروع بطبوط (Batboot)

هذا الدليل يشرح طريقة تشغيل مشروع **بطبوط** على جهاز جديد باستخدام XAMPP
وGitHub وقاعدة بيانات MySQL.

## 1. المتطلبات

ثبّت البرامج التالية على الجهاز الجديد:

-   [XAMPP](https://www.apachefriends.org/) لتشغيل Apache وMySQL وPHP.
-   [Git](https://git-scm.com/downloads) لتنزيل المشروع من GitHub.
-   متصفح حديث مثل Chrome أو Edge.
-   Visual Studio Code اختياري لتعديل ملفات المشروع.

## 2. تنزيل المشروع من GitHub

1.  افتح مستودع Batboot على GitHub.
2.  اضغط **Code** ثم انسخ رابط HTTPS.
3.  افتح PowerShell أو Terminal ونفّذ الأمر التالي، مع استبدال الرابط
    برابط المستودع الفعلي:

``` bash
git clone https://github.com/USERNAME/Batboot.git
```

4.  انقل مجلد المشروع الناتج إلى مجلد خادم XAMPP:

``` text
C:\xampp\htdocs\batboot
```

> إذا كان المشروع موجودًا مسبقًا داخل `htdocs`، لا تنشئ مجلدًا متداخلًا
> بالخطأ. تأكد أن ملفات مثل `login.html` ومجلد `php` موجودة مباشرة داخل
> مجلد المشروع.

## 3. تشغيل خدمات XAMPP

1.  افتح **XAMPP Control Panel**.
2.  اضغط **Start** بجانب Apache.
3.  اضغط **Start** بجانب MySQL.
4.  تأكد أن الخدمتين تعملان دون أخطاء.

## 4. نقل قاعدة البيانات من الجهاز القديم

قاعدة البيانات لا تنتقل مع ملفات GitHub. يجب تصديرها من الجهاز القديم ثم
استيرادها على الجهاز الجديد.

### على الجهاز القديم: تصدير قاعدة البيانات

1.  افتح:

    `http://localhost/phpmyadmin`

2.  اختر قاعدة البيانات `batboot_db`.

3.  افتح تبويب **Export**.

4.  اختر طريقة **Quick** وصيغة **SQL**.

5.  اضغط **Export** واحفظ ملف SQL في مكان آمن.

### على الجهاز الجديد: استيراد قاعدة البيانات

1.  افتح:

    `http://localhost/phpmyadmin`

2.  أنشئ قاعدة بيانات جديدة باسم:

    `batboot_db`

3.  اختر قاعدة البيانات الجديدة.

4.  افتح تبويب **Import**.

5.  اختر ملف SQL الذي صدرته من الجهاز القديم.

6.  اضغط **Import** وانتظر ظهور رسالة نجاح الاستيراد.

> لا ترفع ملف قاعدة البيانات الذي يحتوي على بيانات الأطفال إلى مستودع
> GitHub عام. انقله بشكل خاص وآمن، ولا تشاركه إلا مع الأشخاص المخولين.

## 5. إعداد اتصال PHP بقاعدة البيانات

افتح الملف:

`php/db.php`

تحقق من إعدادات الاتصال. مثال لإعداد XAMPP المحلي الافتراضي:

``` php
$host = '127.0.0.1';
$dbname = 'batboot_db';
$username = 'root';
$password = '';
```

قد تختلف هذه القيم حسب إعداد MySQL على الجهاز الجديد. إذا كان حساب MySQL
لديه كلمة مرور، اكتبها في قيمة `$password`. لا تحفظ كلمات المرور
الحقيقية في مستودع GitHub؛ استخدم إعدادات محلية غير منشورة إذا كان
المشروع مجهزًا لذلك.

## 6. فتح الموقع

بعد تشغيل Apache وMySQL والتأكد من إعداد قاعدة البيانات، افتح:

`http://localhost/batboot/login.html`

إذا كان اسم مجلد المشروع مختلفًا، استبدل `batboot` في الرابط باسم المجلد
الفعلي.

## 7. ملاحظات حول ملفات المشروع

-   احتفظ بملف `.htaccess` لأنه يحتوي قواعد Apache لإعادة كتابة بعض
    الروابط.
-   تأكد من وجود مجلدات وملفات المشروع كاملة، ومنها `css` و`js` و`php`
    و`rec` إن كانت مستخدمة في النسخة.
-   إذا لم تعمل الروابط المعاد كتابتها، تحقق من تفعيل وحدة `mod_rewrite`
    في Apache والسماح باستخدام `.htaccess` في إعدادات الخادم.
-   إذا ظهرت أخطاء اتصال بقاعدة البيانات، راجع إعدادات `php/db.php`
    وتأكد أن MySQL يعمل وأن قاعدة البيانات اسمها `batboot_db`.

## 8. ملف ترحيل التقدم والنجوم

قد يحتوي المشروع على ملف باسم `progress-migration.sql`.

هذا الملف مخصص لتعديل بنية أو بيانات جداول التقدم والنجوم. **لا تنفذه
تلقائيًا عند كل تشغيل أو بعد استيراد قاعدة بيانات سبق ترحيلها.**

قبل تنفيذه:

1.  خذ نسخة احتياطية من قاعدة البيانات.
2.  اقرأ أوامر الملف وتأكد من توافقها مع بنية قاعدة البيانات الحالية.
3.  افحص وجود سجلات مكررة قبل إضافة أي مفتاح فريد.
4.  نفّذ الترحيل فقط إذا كانت قاعدة البيانات تحتاج هذه التعديلات.

إذا لم تكن متأكدًا من حالة قاعدة البيانات، اطلب من مسؤول المشروع مراجعة
ملف الترحيل قبل التنفيذ.

## 9. تحديث المشروع لاحقًا من GitHub

إذا كان المشروع قد نُزّل باستخدام `git clone`، افتح Terminal داخل مجلد
المشروع ونفّذ:

``` bash
git pull origin main
```

هذا يحدّث ملفات المشروع من GitHub. لكنه **لا يحدّث قاعدة بيانات MySQL
تلقائيًا**. راجع أي ملفات SQL أو تعليمات ترحيل جديدة قبل تطبيق تغييرات
قاعدة البيانات.

## 10. حل مشكلات شائعة

  -----------------------------------------------------------------------
  المشكلة                             ما يجب التحقق منه
  ----------------------------------- -----------------------------------
  لا يفتح الموقع                      تأكد أن Apache يعمل، وأن مجلد
                                      المشروع داخل `C:\xampp\htdocs`، وأن
                                      الرابط صحيح.

  خطأ في اتصال قاعدة البيانات         تأكد أن MySQL يعمل، وأن قاعدة
                                      `batboot_db` موجودة، وأن بيانات
                                      `php/db.php` صحيحة.

  صفحة محمية لا تفتح                  تحقق من تسجيل الدخول والجلسة، ومن
                                      إعدادات `.htaccess` و`mod_rewrite`.

  الصور أو الملفات لا تظهر            تأكد من نقل مجلدات الأصول مثل `rec`
                                      وبقية ملفات المشروع.

  التقدم أو النجوم لا تظهر            افحص طلبات `php/me.php`
                                      و`php/save-progress.php` في أدوات
                                      المطور، ثم راجع سجلات PHP وقاعدة
                                      البيانات.
  -----------------------------------------------------------------------

## قائمة تحقق سريعة

-   [ ] تثبيت XAMPP وGit.
-   [ ] تنزيل المشروع إلى `C:\xampp\htdocs\batboot`.
-   [ ] تشغيل Apache وMySQL.
-   [ ] إنشاء قاعدة `batboot_db` واستيراد ملف SQL.
-   [ ] مراجعة إعدادات `php/db.php`.
-   [ ] فتح `http://localhost/batboot/login.html`.
-   [ ] تسجيل الدخول وتجربة درس والتحقق من حفظ التقدم.
-   [ ] عدم تنفيذ `progress-migration.sql` دون نسخة احتياطية ومراجعة.
